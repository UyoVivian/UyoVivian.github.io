CASE STUDY

Building visibility into Azure security activity

This project focused on improving centralized security monitoring in Microsoft Azure. My contribution centered on data ingestion and compliance, helping ensure that relevant Azure security telemetry was connected to Microsoft Sentinel and available for investigation and validation.

What I worked on

I supported the integration of Azure Activity Logs and Microsoft Defender for Cloud with the Log Analytics workspace and Microsoft Sentinel. When the Azure Activity Logs connector was not initially connected as expected, the team used the Azure Activity Logs export configuration to route the required telemetry into the workspace.

How I validated the integration

After configuring the data sources, I used KQL queries in Log Analytics to confirm that security telemetry was being ingested and could be queried successfully. This validation helped demonstrate that the monitoring configuration was not simply enabled, but actually producing usable security data.

Security and compliance value

Centralized visibility helps security teams investigate cloud activity, identify suspicious changes, and maintain evidence of monitoring controls. The project also considered how the monitoring approach could support security and compliance objectives such as SOC 2 and ISO/IEC 27001 by improving visibility, traceability, and security-event monitoring.
